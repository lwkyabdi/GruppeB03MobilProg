# MovieMate – mobilprogrammering

App for MovieMate, bygget med Expo/React Native. Lar brukeren søke etter
filmer, lagre dem i en watchlist, markere favoritter, og gi egen rating og
kommentar.

## Krav

- Node.js 22.12 eller nyere
- npm 11 eller nyere

## Komme i gang

```bash
npm install
npx expo start
```

I output finner du valg for å åpne appen i development build, Android-emulator,
iOS-simulator, eller Expo Go.
